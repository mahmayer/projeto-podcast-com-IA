# Projeto Podcast Gerado por IAs

ℹ️ NOTE: Este é o repositório desenvolvido para o Bootcamp da DIO - Prompts Inteligentes


Projeto com o objetivo de gerar um podcast utilizando ferramentas de IA através de prompts mais trabalhados.


## 💻 Tecnologias utilizadas no projeto
* ChatGPT >> Roteiro
* ElevenLabs >> Audio
* MidJourney >> Imagem da capa
* Capcut >> Edição do aúdio


## 🛠️ Como foi feito?
* 🤖 1. O título e o roteiro do podcast foi gerado com o auxílio do ChatGPT. Modelo de prompt utilizado em: 📁prompts
* 🤖 2. O aúdio do roteiro foi gerado no ElevenLabs. O roteiro gerado pelo ChatGPT foi utilizado no ElevenLabs.
* 🤖 3. A capa do podcast foi gerada no Midjourney. Modelo de prompt utilizado em: 📁prompts
* 🤖 4. O Capcut foi utilizado para tratar o aúdio e adicionar sons de fundo.
* ✨ Resultado do projeto em: 📁output
